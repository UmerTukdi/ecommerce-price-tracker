# E-commerce Price Tracker & Analysis

## Project Overview
This project focuses on scraping product data from an e-commerce website and
analyzing pricing and rating patterns using Python.

## Tools & Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Structure
- scraper.ipynb: Web scraping logic
- analysis.ipynb: Data analysis and visualizations
- data/products.csv: Scraped dataset

## Outcome
The project demonstrates the ability to collect external data through web
scraping and transform it into meaningful business insights.
